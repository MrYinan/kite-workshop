# kite-workshop  纸鸢非遗 · 鸢时漫记

> 一纸鸢，一线牵。

“纸鸢非遗 · 鸢时漫记”是一个以纸鸢文化与非物质文化遗产传承为主题的网页项目。网站围绕纸鸢的历史、制作技艺、文化故事与研学体验展开，通过图文展示与专题页面，让访客更加直观地了解纸鸢文化的独特魅力。

## 在线访问

项目网页地址：  
[https://mryinan.github.io/kite-workshop/](https://mryinan.github.io/kite-workshop/)

## 项目内容

网站主要包含以下模块：

- **纸鸢学习**：了解纸鸢的材料、骨架、绘制与制作流程。
- **纸鸢观赏**：浏览具有代表性的纸鸢作品与相关图片。
- **文化阅读**：通过图文内容了解纸鸢的历史故事与非遗传承。
- **研学路线**：展示与纸鸢文化相关的研学活动和体验路线。
- **文创展示**：呈现纸鸢主题文创产品与文化衍生内容。
- **联系我们**：提供项目相关的联系信息。

## 项目说明

本项目为静态网页项目，可直接通过上方链接在线访问。网站旨在以数字化形式传播纸鸢文化，让更多人认识、了解并关注传统纸鸢技艺及其非遗价值。
